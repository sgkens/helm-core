# Architecture decision records

Use a decision record when a choice changes a durable boundary, public contract, performance strategy or source of truth. Copy `0000-template.md`, assign the next four-digit number, and use a short kebab-case name.

Accepted records are immutable historical context. If a decision changes, add a new record and mark the old one superseded. Small implementation details and temporary plans belong in merge requests or the development tracker instead.
