# v0.40.0-release

## Added

- Rotating display pages with `rotate:`.
- Dynamic binding freshness with `ttl:`, `.age`, and `.fresh`.
- HELM-tagged unicast message support.
- Undo and redo in HELM Toolbox.
- Documentation sitemap, robots, and `llms.txt` files.
- GitLab Release publishing from release tags.
- ZIP download and Workshop links in release descriptions.
- Permanent download paths for release assets.
- Workshop preview assets and change notes.

## Changed

- Process pending messages on scheduled runs, limited to eight messages per listener per run.
- Require matching release notes and the versioned ZIP before publishing.
- Retrieve build artifacts and wait for release checks before package upload.
- Include changelog and release notes in release ZIPs.
- Update gauge, DSL, installation, and inter-script documentation.
- Update the project banner and Workshop description.

## Fixed

- Reject non-finite numeric payloads without replacing the last valid value.
- Handle Workshop headings without decorative symbols.
- Handle Quick Start as the final Workshop description section.
