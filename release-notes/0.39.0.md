# HELM Core v0.39.0

This release adds rotating display pages, live-data freshness indicators, and undo and redo in HELM Toolbox.

## Display and inter-script updates

- Share an output between several pages with `rotate:`. Every page on the output must use the same interval of at least one second.
- Set `ttl:` on dynamic bindings and use `.age` and `.fresh` to show whether received data is current. The default freshness window is ten seconds; `.age` is `-1` before any value arrives, and `.fresh` is `100` while current or `0` otherwise.
- Receive HELM-tagged string payloads over broadcast or unicast. Scheduled runs also process pending messages, with bounded work per listener.
- Reject non-finite numeric payloads without replacing the last valid value.

## Toolbox and documentation

- Undo and redo layout edits, including grouped typing and atomic editor actions, with restored selections.
- Updated examples and guidance for gauges, the DSL, installation, and inter-script integration.
- Added sitemap, robots, and `llms.txt` discovery files to the documentation site.

## Publishing

- Explicit `vMAJOR.MINOR.PATCH-release` tags create a GitLab Release after validation and package upload.
- Release assets include the versioned ZIP containing the combined scripts, layouts, Workshop reference, README, changelog, and release notes.
- Workshop publishing includes preview assets and change notes while preserving the full description on existing items.
- Fixed Workshop staging when section headings omit decorative symbols, and when Quick Start is the final section.

## Updating an existing Programmable Block

Replace the script with `HelmCombined.min.cs` from the ZIP, or select the updated Workshop subscription in **Edit → Browse Scripts**, then run `reload`. Your layout remains in the block's Custom Data. Updating a Workshop subscription alone does not replace code already pasted into a block.
