# Border Styles Gallery
# One panel per border style. In game only the screen-level style matters (ascii and none differ); panel-level border: renders in helmv.ps1 only.

@screen Borders

profile: auto
layout: grid(4, 2)

@panel ascii at(1, 1, 1, 1) title: "ASCII" border: ascii
